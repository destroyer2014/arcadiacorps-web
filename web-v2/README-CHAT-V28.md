# ArcadiaCorps Chat v28

Primera versión del chat privado: conversaciones 1 a 1, buscador de usuarios, mensajes en tiempo real, imágenes, no leídos, borrado propio, bloqueos y etiquetas de rol.

## Instalación
1. Copiar todos los archivos dentro de `web-v2/`.
2. Ejecutar `supabase/chat-v28.sql` en Supabase SQL Editor.
3. Desplegar y abrir `chat.html?v=28`.

## Nota
Las respuestas a historias se conectarán en una actualización posterior, después de validar este chat base.
