# ArcadiaCorps Web 2.0 — Perfil funcional

Incluye login rediseñado, perfil real, edición de nombre/usuario/teléfono, carga de avatar desde el dispositivo, cuentas vinculadas, información de cuenta y cambio de contraseña.

Antes de probar la carga de avatar, ejecutar `supabase/profile-storage-v2.sql` en el SQL Editor de Supabase.
