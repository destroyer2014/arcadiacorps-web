# Noticias y anuncios — Web 2.0

1. Ejecuta `supabase/news-v2.sql` en Supabase SQL Editor.
2. Despliega todos los archivos de `web-v2`.
3. Abre `news.html`.
4. Las cuentas Owner y Staff verán “Nueva publicación”.
5. Los usuarios autenticados pueden leer y comentar.

No incluye datos de demostración. La tabla comienza vacía.
