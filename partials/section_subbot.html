Tu propio bot

Cómo hacerte Sub-Bot

Conecta tu propio número de WhatsApp como una extensión de Pragmata Bot, con sesión real vía código de vinculación.

01

Verifica tu plan

Necesitas Premium activo. El plan determina cuántos sub-bots puedes tener conectados a la vez.

02

Ejecuta el comando

Escribe .code en tu chat con el bot principal.

03

Recibe tu código

El bot te enviará un código de vinculación al privado. Ábrelo desde WhatsApp → Dispositivos vinculados → Vincular con número de teléfono.

04

Tienes 60 segundos

Si no lo usas a tiempo, el bot genera un nuevo código automáticamente.

05

¡Listo!

Tu número queda conectado como sub-bot. Usa !subbot list para ver tus sesiones activas o !subbot remove para desconectar una.

Conecta tu Sub-Bot ahora

Escribe tu número y te generamos el código de vinculación aquí mismo, en vivo.

TU CÓDIGO DE VINCULACIÓN
— — — —
  1. Abre WhatsApp en tu teléfono.
  2. Ve a Ajustes → Dispositivos vinculados.
  3. Toca Vincular un dispositivo → Vincular con número de teléfono.
  4. Escribe el código de arriba.

El código dura 60 segundos una vez generado. Si expira, pide uno nuevo.
