# Astharot RPG Android v9

Incluye intro animada de ArcadiaCorp con sonido original, nueva pantalla de carga, apertura obligatoria en login, creación de héroe con respaldo local, interfaz compacta para móviles horizontales y modo inmersivo moderno.

Sube `astharot-mobile/` y `.github/workflows/build-apk.yml`, haz commit y push. Descarga el artefacto `Astharot-RPG-debug-v9` desde GitHub Actions.
